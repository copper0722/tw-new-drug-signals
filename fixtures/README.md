# fixtures

**這些是測試樣本，不是資料鏡像。**

本 repo 刻意不鏡像任何資料（理由見 [README 的〈刻意不做〉](../README.md)）。
這裡的檔案只大到夠讓測試涵蓋每一種已量測到的形態，並在檔名或 `_meta` 裡帶著
抓取日期與重抓方式。要完整資料，請自己向食藥署的公開來源取得。

全部檔案於 **2026-08-05** 取得。

**重抓欄要照實寫。** 五個檔案裡只有兩個有一行貼上去就能跑的指令；另外三個沒有，
因為本 repo 不提供批次抓取工具（[README〈刻意不做〉](../README.md)）。那三個要寫
清楚**缺什麼**，而不是指向一頁其實沒有指令的文件——一段跑不起來的「重抓方式」
讀起來像已經驗證過，那比留白更糟。

| 檔案 | 內容 | 重抓 |
|---|---|---|

## 兩個 `.jsonl` 的前幾行不是 JSON

兩個 `.jsonl` 樣本都以 `//` 開頭的註解行起頭（來源、組成、以及「不是資料鏡像」）。
**逐行 `json.loads` 會在第一行就炸。** 讀取時要先濾掉空行與 `//` 開頭的行，
隨附程式就是這樣做的（`reference/measure_fixtures.py` 的 `_jsonl()`）：

```python
rows = [json.loads(l) for l in open(path, encoding="utf-8")
        if l.strip() and not l.lstrip().startswith("//")]
```

註解留著是刻意的：一個沒有來源標註的樣本檔，下一個讀者會以為它是資料鏡像。
代價是它不是合法的 JSON Lines，所以這件事必須寫在這裡，不能只寫在程式碼裡。

這些檔案算得出來的數字，全部登記在
[`measurements.json`](../measurements.json) 並且**真的可以跑**：

```console
$ python3 reference/measure_fixtures.py
OK   M-01  got=61  measurements.json=61
...
$ make measurements
```

## `origin` 欄位：真實 vs 合成

兩個 `.jsonl` 樣本的每一列都有 `origin`：

- **`real`** — 逐字取自食藥署的公開資料。標題取自 2026-08-05 的 206 則公告
  （`M-10`），成分字串取自同日的許可證資料。
- **`synthetic`** — 本 repo 自己造的**負控輸入**，用來驗證工具在該拒絕的時候
  真的會拒絕。

組成：標題樣本 46 列 = 42 real + 4 synthetic（`M-26`）；成分樣本 25 列 =
24 real + 1 synthetic（`M-30`）。

這個區分不是形式主義。合成樣本混進真實樣本裡，就等於把自己編的東西放進一個
寫著「以下取自真實資料」的框，而那個框會給裡面的每一列背書（同一條規則見
[CONTRIBUTING §1](../CONTRIBUTING.md)）。所以：**要加負控就加，但一定標
`synthetic`。**

其中一筆合成負控（`第 027864 Testdrug 100mg`）明確寫著它在 206 則真實標題裡
出現 **0 次**（`M-29`），它是預防性守衛而非觀察到的形態。這種註記是必要的：一個
沒有標註的守衛，下一個讀者會以為它對應某個真實案例。**0 是「沒觀察到」，
不是「不可能」**——守衛的存在理由是前者。

## 樣本比例不是母體比例

樣本刻意加重難的形態，所以樣本上的比例比母體高，兩者**不可互相引用**：

| | 樣本（42 列 real） | 全量（206 則） |
|---|---|---|
| 對到超過一張證 | 15（`M-27`） | 41（`M-18`） |
| 貪婪比對抓錯字別 | 15（`M-28`） | 20（`M-22`） |

前一欄可以直接跑（`python3 reference/measure_fixtures.py M-27`）；後一欄需要你
自己把 206 則抓下來。**這正是本 repo 對數字的規矩**：算得出來的就給指令，
算不出來的就講清楚缺什麼，不要含糊帶過。

（R 序號 4 則、無「號」2 則這兩種形態，真實案例全部收在樣本裡，所以樣本數與全量
相同——`M-23`、`M-24`。）

## 一個必須分清楚的數字

碼表有 **61** 筆字別（`M-01`），其中藥品類（排除醫器／粧／色）**31** 種
（`M-02`）。但藥品許可證資料裡實際出現過的字別只有 **26** 種（`M-07`）——碼表列
的是**可能值**，不是**出現值**，兩者不可互相引用。

前兩個數字用隨附的碼表就算得出來；第三個不行，它需要一份完整的許可證表，
**本 repo 不發布**（理由見上）。下面的 SQL 假設你自己有一張每列一張許可證、
且帶許可證號欄的表：

```sql
SELECT count(DISTINCT substring(permit_number from '^(.+?)字第')) FROM <你自己的許可證表>;
-- 26（2026-08-05，母體 66,440 張，`M-05`）
```

沒出現的 5 種藥品類字別是：衛署中藥輸、署藥兼食製、部藥兼食製、衛署菌製、
衛部罕菌疫製。
