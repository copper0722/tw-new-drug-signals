# docs/ — public claims

- Each page opens with the question it answers and ends with both a positive and a
  negative control chosen from the most confusable population.
- Verbatim blocks contain source text only; interpretation/counts stay outside and are
  explicitly attributed.
- Cite measurement IDs rather than duplicating provenance.
- Separate official determination, observed field/list membership, and repo computation.
- State source/version/date and the exact limit of a negative result.
- Commands must run from a clean clone at repo root with every variable defined.
- Reader-facing zh-TW uses precise Taiwan regulatory terminology and avoids confident
  claims beyond inspected authority.
