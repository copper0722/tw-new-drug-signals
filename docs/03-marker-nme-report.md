# 03 — 訊號二：新成分新藥核准審查報告摘要

**這頁回答什麼**：食藥署唯一以「新成分新藥」命名的逐案清單怎麼用，它落後多久，
以及把公告標題解析成許可證號時，四個會讓你安靜地少抓的地方。

清單網址、母體數字與發布落差在 [docs/00 §D](00-sources.md)，這裡不重複。

---

## 這是唯一由食藥署自己命名為「新成分新藥」的逐案清單

<https://www.fda.gov.tw/TC/siteList.aspx?sid=2712>

每一列是一則公告，附一份審查報告 PDF。這是食藥署自己用「新成分新藥」這五個字
命名的清單，所以**它列出來的每一筆都是權威**：那些是逐案審查認定並公告的結果，
正面事實可以直接引用，不需要再從別的欄位推。

標題刻意不寫成「唯一權威的新成分標籤」。那個寫法會脫離上下文被引用，而它把
「這份清單是權威的」偷偷擴大成「不在這份清單上就沒有被認定過」——本頁下面第 2 點
自己就說了：**審查認定可以存在，而這份清單沒收。** 權威的是它列出來的東西，
不是它的邊界。

代價是兩個：**它很慢，而且它的沉默不可用。** 這兩件事只影響「不在上面」的證，
不影響「在上面」的證。

---

## 它慢到什麼程度

| 量測（2026-08-05，273 筆） | 值 | 登記 |
|---|---|---|
| 中位落差（公告日 − 發證日） | **69 天** | `M-14` |
| 落差範圍 | −2,232 天 至 +1,093 天 | `M-15` |
| 公告日早於發證日者 | 1 筆 | `M-15` |

而且**不按核准順序**。那筆負落差不是資料錯誤，也不是一個發布現象：它是
[docs/06](06-permit-identity-and-dates.md) 那個 dupilumab 案例（`M-21`）——
公告發於 2018 年，而該證儲存的發證日是換發後的 2025 年。**所以 −2,232 這個
下界量的是日期欄位，不是公告速度**，談「公告最多可以早幾天」時不能用它。

### 沉默讀不出東西來

這份清單的**列**是權威的：它列出來的每一筆，都是食藥署自己審查認定並公告為
新成分新藥的。**它的沉默不是。** 一個號碼不在上面，至少有三種可能，而資料本身
分不出是哪一種：

1. 已核准，但還沒公告（中位落後 69 天，`M-14`）。
2. 已審查認定，但沒有進到這一份清單裡（清單有它自己的收錄範圍，而收錄準則
   食藥署沒有公開）。
3. 確實不是新成分新藥。

所以能寫下來的結論只有一句：**沉默不能讀成否定。** 早期版本這裡寫的是「沉默
永遠是還沒公告」——那把三種可能壓成一種，等於替食藥署宣布了它沒說的事。

而且它的沉默還會**持續很久**。逐年公告則數（`M-16`）：2012 年 7、2013 年 2、
2014 年 3，接著 **2015、2016、2017 三年整年掛零**，2018 年恢復為 18 則，之後的
完整年度落在 15–32 則（2026 為部分年度）。任何「這個清單多久沒動 → 出事了」的
告警，門檻要用**月**為單位；用「幾天沒更新」當條件，這個清單會讓你的告警在正常
年份就一直響。

實例：2026-08-05 當下，本 repo 拿來當控制樣本的四個具名 2026 新分子裡，這個清單
只收錄了兩個，SEVABERTINIB 與 BELZUTIFAN 不在上面。**這不代表它們不是新成分
新藥，也不代表它們是——這份來源在這個問題上沒有給答案。**

## 四個解析陷阱

所有片段**逐字取自 2026-08-05 的 206 則真實公告標題**（`M-10`）。整份樣本
（46 列：42 列真實、4 列明確標示的合成負控，`M-26`）在
[`fixtures/nme_titles.sample.jsonl`](../fixtures/nme_titles.sample.jsonl)；
參考實作在 [`reference/tw_nme_titles.py`](../reference/tw_nme_titles.py)。

**下面 (a)–(d) 的比例都是跑在全部 206 則上的**，而本 repo 只隨附其中 46 則。
要自己重跑這些比例，你得先向 §來源 那個公開網頁把整份清單抓下來；隨附樣本
算出來的是另一組數字（樣本刻意加重了難的形態，見
[`fixtures/README.md`](../fixtures/README.md)）。**樣本比例不能拿來代表母體。**

### (a) 一則公告可以帶好幾張證

| 量測（206 則 / 273 張證） | 值 | 登記 |
|---|---|---|
| 標題的序號酬載使用範圍或列舉寫法 | **36 / 206 = 17.5%** | `M-17` |
| 標題實際對到超過一張證 | **41 / 206 = 19.9%** | `M-18` |
| 只取每則第一張證會漏掉的證數 | **67 / 273 = 24.5%** | `M-19` |

兩個定義差在哪：36 則是「序號那一段裡有分隔符」，另外 5 則是**寫了兩個完整的
許可證號**，所以 36 + 5 = 41。

已量測到的分隔符與出現則數（`M-20`）：`-` 26 則、`、` 7 則、`/` 2 則、`~` 1 則。
這是**已量測到的形態，不是保證的完整集合**——參考實作另收了全形變體，因為成本
為零。真實形態：

```
台灣禮來股份有限公司  衛部藥輸字第027640-027643號「捷癌寧膜衣錠」
台灣拜耳股份有限公司 衛部藥輸字第027746-027748號 維泰凱膠囊25毫克、維泰凱膠囊100毫克及維泰凱20毫克/毫升口服溶液
台灣優時比貿易有限公司 衛部藥輸字第027714~027719號 「必治癲膜衣錠、注射液、口服溶液」
台灣諾和諾德藥品股份有限公司 衛部菌疫輸字第001160-64號 「諾和長效第八因子注射劑 500、1000、1500、2000、3000 IU」
美商惠氏藥廠（亞洲）股份有限公司台灣分公司 衛部菌疫輸字第001196、97號「能增樂預填充注射筆24、60毫克」
台灣拜耳股份有限公司 衛部藥輸字第028325、26號 「可申達10、20毫克膜衣錠」
台灣諾華股份有限公司 衛部菌疫輸字第001127/001128號 「安莫疼注射液劑70毫克/毫升 /140毫克/毫升 」
台灣諾華股份有限公司 衛部罕菌疫輸字第000044號「樂適達注射劑」、衛部菌疫輸字第001209號「"諾華"樂喜達注射劑」
```

注意最後兩則的難處：`001127/001128` 後面的產品名裡也有斜線和數字
（`70毫克/毫升 /140毫克/毫升`），而最後一則的兩張證**字別不同**
（衛部罕菌疫輸／衛部菌疫輸），不能沿用第一個字別。

**短尾寫法**（`001160-64`、`001196、97`、`028325、26`）是最容易寫錯的一種：
尾巴只給末幾碼，前綴要沿用前一個序號。26 則屬於這一類。

### (b) 字別是封閉集合，必須最長匹配

標題常常把公司名直接接上許可證，中間沒有空白：

```
台灣武田藥品工業股份有限公司衛部藥輸字第027623號「福星定膜衣錠20毫克…」
高端疫苗生物製劑股份有限公司衛部菌疫製字第000152號「"高端"腸病毒71型疫苗」
法商益普生股份有限公司台灣分公司衛部藥輸字第027513號「癌必定膜衣錠 60毫克」
恩典科研股份有限公司衛部藥輸字第R00105號「鎵連坊鍺68/鎵68孳生器」
```

用 `[一-鿿]+字第` 這種貪婪的中文字元類，第一則會抓到
`台灣武田藥品工業股份有限公司衛部藥輸`。

**量測**：在 206 則標題上，貪婪比對有 **20 則**抓到不在碼表內的字別（`M-22`）——
19 則是公司名黏上去，1 則是來源錯字（見陷阱 d）。

正解是拿 61 筆的 `Lic.Type` 碼表當封閉集合（`M-01`），從右往左取**最長**的合法
字別。最長匹配不是保險起見：`衛部藥輸` 與 `衛部藥製` 都存在，短匹配會挑錯。

判準長這樣。整段可以直接貼進 repo 根目錄跑，`titles` 先從隨附樣本裝起來——
換成你自己的標題清單就是你的量測：

```python
import json, re

titles = [r["title"] for r in
          (json.loads(l) for l in open("fixtures/nme_titles.sample.jsonl")
           if l.strip() and not l.startswith("//"))
          if r["origin"] == "real"]

codes = {c["lic_type"] for c in
         json.load(open("fixtures/lic_type_codes.2026-08-05.json"))["codes"]}
bad = [t for t in titles
       if (m := re.search(r"([一-鿿]+)字第", t)) and m.group(1) not in codes]
print(len(bad))   # 15
```

樣本的 42 則真實標題得到 15（`M-28`）；同一段判準跑全部 206 則會得到 20
（`M-22`）。樣本刻意收了較高比例的難例，所以兩個數字不同是預期的，
**樣本比例不能拿來代表母體**。同一個值也可以不貼程式碼直接算：

```console
$ python3 reference/measure_fixtures.py M-28
15
```

早期版本這裡的片段用了一個從未定義的 `titles`，貼上去只會拿到 `NameError`。
**一段跑不起來的「重跑方式」不是重跑方式**，它只是看起來像。

### (c) 序號可以用字母開頭

```
台灣諾華股份有限公司 衛部藥輸字第R00104號「鎦癌平注射液370百萬貝克/毫升」
行政院原子能委員會核能研究所核醫製藥中心之「核研[氟-18]氟化鈉注射劑（衛署藥製字第R00032號）
台灣諾華股份有限公司「樂鎵美25微克放射性顯影劑製備試劑組」(衛部藥輸字第R00108號)
```

放射性藥品的序號是 `R` 開頭。以 `[0-9]` 錨定序號，這 **4 則**全漏（`M-23`）。
這 4 則真實案例全部收在隨附樣本裡，所以樣本上的數字與全量相同，可以直接跑：
`python3 reference/measure_fixtures.py M-23`。

R 序號本身已經是 6 字元，**永不補零**——補成 7 字元的序號，licId 就會變成
9 字元（正常是 8），見 [docs/06](06-permit-identity-and-dates.md)。也不要對字母序號做範圍展開：
它的遞增規則沒有被量測過，猜會出錯，參考實作選擇丟例外。

### (d) 「號」不一定在，空白不一定不在

```
運和生技有限公司 衛部藥輸字第028106「期樂錠 50毫克 」
羅氏大藥廠股份有限公司「癌妥飛 3毫克膜衣錠、9毫克膜衣錠」(衛部藥輸字第028944-45)
科進製藥科技股份有限公司「脂妙清軟膠囊1000毫克」(衛部藥製字第059019 號)
羅氏大藥廠股份有限公司 衛部藥輸字第 027864/027865號 「羅思克 100 毫克 / 200 毫克膠囊」
台灣武田藥品工業股份有限公司 衛部藥字第027731號「癌能畢 膜衣錠90毫克」
```

依序是：完全沒有「號」（**2 則**，`M-24`；兩則都收在隨附樣本裡，
`python3 reference/measure_fixtures.py M-24`）、許可證寫在括號裡排在產品名之後、
「號」前有空白、「第」後有空白、以及**來源錯字**——`衛部藥字` 不是任何一個
合法字別。

錯字那一則的正解是拿序號 `027731` 到許可證表反查，得到 `衛部藥輸字第027731號`。
**不要猜。** 這次猜「衛部藥輸」剛好會對，但那是運氣不是方法：同一個序號在
`衛部藥製` 底下也可能存在。參考實作在這裡回報「無法解析」而不是回傳猜測值。

因為「號」不保證存在，序號酬載的終止條件不能只有「號」。參考實作的規則是：
**酬載是「第」之後一段不含空白的英數與分隔符**。允許酬載含空白，
`第 027864 Testdrug 100mg` 這種形態就會把產品名整段吃成序號。

## 展開是假設，「存在」才是檢定

把 `第029081-82號` 展開成兩張證，那只是一個**候選集合**。真正的檢定是
「它存在於許可證資料裡嗎」。2026-08-05 的結果是 **273 / 273 全部存在**
（`M-12`），所以這一輪的展開規則沒有製造出虛構的許可證（母體 273 張見 `M-11`）。

這是一個**外部**檢定——拿自己的解析結果去對一份不是自己產生的資料——所以它是
有意義的 100%。但它只證明「沒有造假」，不證明「沒有漏抓」。漏抓要另外量：把
參考實作跑過全部 206 則，**205 則的結果與資料裡實際登錄的證號集合完全一致**
（`M-25`）；唯一不一致的那一則是陷阱 (d) 的來源錯字「衛部藥字第027731號」，
參考實作依設計回報無法解析，而不是猜一個。**那一則是刻意的拒絕，不是失敗。**

參考實作刻意不連網也不查表，所以它回傳的永遠是候選；檢定是呼叫端的責任。
`test_expansion_is_a_hypothesis_not_a_conclusion` 把這個契約釘住：一個語法完全
合法但完全虛構的號碼，照樣會被展開出來。

## 怎麼確認我沒搞錯

| 檢查 | 正控（必須成立） | 負控（必須不成立） |
|---|---|---|
| 多證公告沒漏 | `第027714~027719號` 展開成 6 張 | 只回 1 張 |
| 短尾展開對 | `第001196、97號` → `001196`、`001197` | 展開成 `001196`、`000097` |
| 字別沒吃到公司名 | `…有限公司衛部藥輸字第027623號` → 字別 `衛部藥輸` | 字別含「有限公司」 |
| 產品名沒被當序號 | `第028325、26號「可申達10、20毫克膜衣錠」` → 2 張 | 出現 `000010`、`000020` |
| 錯字沒被猜 | `衛部藥字第027731號` → 回報無法解析 | 直接回 `衛部藥輸字第027731號` |
| 展開沒造假 | 你的候選 100% 在許可證表裡查得到 | 有查不到的仍然收進清單 |
| 沉默沒被讀成否定 | 「這個號碼不在這份清單上」 | 「所以它不是新成分新藥」 |

全部 46 筆樣本（`M-26`）逐筆比對的測試在
[`reference/tests/test_nme_titles.py`](../reference/tests/test_nme_titles.py)。
抽樣通過不算數——陷阱就藏在你沒抽到的那幾筆。所以除了樣本，參考實作也跑過全部
206 則並與實際登錄的證號集合逐則比對（`M-25`）。
